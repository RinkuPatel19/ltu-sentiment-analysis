# Social Media Sentiment Analysis – LTU

## 📌 Overview
This project analyzes social media feedback related to Lawrence Technological University using Natural Language Processing (NLP) techniques.

## 🎯 Problem Statement
Universities receive large volumes of unstructured feedback from platforms like Twitter, Reddit, and Glassdoor, making it difficult to monitor sentiment and respond to issues.

## 🛠 Tools Used
- Python
- Pandas
- NLTK
- TextBlob
- Matplotlib
- Seaborn

## 📊 Dataset
- 500 social media posts  
- Platforms: Twitter, Reddit, Glassdoor  
- Includes text, date, platform, sentiment  

## ⚙️ Approach
- Data cleaning (stopwords, lemmatization)
- Sentiment classification using TextBlob
- Trend and frequency analysis
- Visualization of sentiment distribution

## 📈 Results
- Achieved **92% accuracy**
- Positive: 45.8%
- Negative: 43%
- Neutral: 11%

## 🔍 Key Insights
- Communication issues drive negative sentiment
- Positive feedback linked to professors and resources
- Sentiment varies across platforms and time
